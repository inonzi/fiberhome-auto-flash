# 烽火系列光猫 5585-CT/5585-CU/5382A 一键刷机工具（支持北京联通）

> 支持型号：**5585F-CT / 5585F-CU / 5382A**（AN7581 平台）
>
> 一款 Windows 命令行小工具： 主要简化刷机前置准备工作，快速部署stock2ubi免刷工具，快速备份，一键原厂到Ponwrt系统，另外附带光猫常用功能菜单，集 开Telnet/查超密/查地区/重启/恢复出厂等

---

## ✨ 功能特色

### 🔍 闪存自动识别与引导适配（核心亮点）

本工具按 `[4]` 自动读取闪存的**芯片型号与容量**，再按型号自动选择引导方案，**无需人工判断**。

**闪存适配一览（按处理方式分类）**

**① 常规闪存（如铠侠）—— 直接刷正式引导**

| 闪存型号                  | 验证状态                         |
| --------------------- | ---------------------------- |
| `TC58NVG1S3HTAI0`（铠侠） | ✅ 实机免拆刷机成功                   |
| 其他未列出的型号              | 默认按标准流程刷正式引导，建议先按 `[4]` 确认型号 |

**② 特定闪存（天海/华邦）—— 自动改用临时过渡引导刷入，进 U-Boot 后再自动换成正式引导**

| 闪存型号                         | 验证状态                |
| ---------------------------- | ------------------- |
| `W29N02KVSIAF`（华邦）           | ✅ 实机免拆刷机成功          |
| `S34ML02G300TFI00`（SkyHigh）  | ✅ 实机免拆刷机成功          |
| `S34ML02H200TFI000`（SkyHigh） | ⏳ 流程已适配，待实机验证（暂无机器） |

**关于为什么存在不同闪存用不同引导的适配，这里可以直接看大佬的完整研究报告：**
[https://github.com/xe5700/uboot-an758x-winbond/blob/main/NAND-ECC-问题报告.md](https://github.com/xe5700/uboot-an758x-winbond/blob/main/NAND-ECC-%E9%97%AE%E9%A2%98%E6%8A%A5%E5%91%8A.md)

### 🖥️ 一键免拆刷机

- `[9]` **原厂直通 PonWrt**：备份 → 刷引导 → 刷固件 → 重启进 OpenWrt，全程自动

- 也可分步操作：`[7]` 只刷引导，设备重启进 U-Boot 页面后再用 `[8]` 刷固件。

- **第三方固件可选**：`firmware/` 目录支持放多个 `.itb` 固件，只有 1 个直接用、多个就在动手前让你选好并全程锁定，中途不再弹窗——不锁死默认固件，方便测试不同版本。

- **自动生刷刷机信息**：刷机成功后全流程日志自动保存到 `info/` 目录（带 MAC），出问题可拿日志检查。

### 🧰 日常维护工具箱

读取设备信息 / 管理员账号 / PPPoE 宽带账号 / 注册信息，修改注册信息，开关 Telnet（自动推算登录与提权密码），重启 / 恢复出厂，获取系统日志下载链接，一键配置电脑双 IP（192.168.1.10 / 192.168.0.10）。

## ⚠️ 开始之前必读

1. **刷机有变砖风险**，刷之前请务必先备份（工具也会强制先备份）。
2. 请在 **Windows 电脑**上运行；弹出防火墙提示请点**允许**
3. 刷机过程中**不要断电、不要拔网线**。
4. **目录和文件名请勿改名或移动**，工具按固定路径找文件；不同机型的文件不要混放。
5. 本工具仅供个人设备维护与技术研究使用，刷机风险自负。

## 快速开始（第一次刷机）

1. **选机型**：主菜单按 `[2]`，选择你的光猫型号。
2. **下载依赖**：按 `[P]` 联网自动下载所需工具、引导和固件（之前下载过会自动跳过）。
3. **配置网络**：按 `[1]`，工具自动给电脑配置双 IP。
4. **（建议）先单独备份**：按 `[6]` 跑一次备份，确认备份目录里文件齐全；顺带按 `[4]` 看一眼闪存型号。
5. **一键刷机**：按 `[9]` 原厂直通 PonWrt，剩余流程工具自动完成。

> 也可以分两步走：`[7]` 只刷引导 → 设备重启进 U-Boot 页面后，再用 `[8]` 刷固件。`[9]` 就是把这两步连起来自动做完。

## 备份说明

- 备份前可选范围：**全分区备份**（推荐，最稳）或 **只备份 factory 分区**（快，刷机够用）；5 秒无操作默认全分区。
- 每个分区下载后都会自动做 MD5 校验。
- `apps`、`userdata` 可能是动态数据分区，校验不符不一定代表备份出错（数据可能正在写入），此时会给你三个选择：
  - 纯备份 `[6]`：10 秒无操作默认**保留文件继续备份**；
  - 刷机 `[7]/[9]`：30 秒无操作默认**中止刷机**（想继续需手动选择）。
- 其他任何分区校验失败都会**直接终止**，不做询问——这是为了防变砖。

## 目录结构

```
程序根目录/
├── fiberhome_tool.exe         主程序
├── files_sha256.json          官方 SHA256 校验表【自动生成】
├── tools/                     依赖工具（[P] 下载到这里）
└── <机型目录>/                 5585F-CT / 5585F-CU / 5382A
    ├── uboot/                 正式引导
    ├── fix_uboot/             特定闪存的临时过渡引导
    ├── firmware/              系统固件（.itb，可放多个）
    ├── info/                  设备信息与刷机日志【自动生成】
    └── backup_mtd/            分区备份【自动生成】
        └── <光猫MAC>/         每台光猫一个目录
```

> 目录名、层级和文件名请勿修改；程序放在根目录运行即可，中文路径也可以。在程序里按 `[F]` 可随时查看带说明的完整版本。

## 常见问题

| 问题            | 处理                                                    |
| ------------- | ----------------------------------------------------- |
| 双击闪退 / 功能没反应  | 右键「以管理员身份运行」                                          |
| 网络配置没生效       | UAC 弹窗请选「是」；配置后工具会自动验证                                |
| 设备侧下载超时 / 连不上 | 手动放行防火墙入站端口，或临时关闭防火墙后重试                               |
| 预检提示缺文件       | 按 `[P]` 一键下载依赖；`factory-1m.bin` 由 `[6]` 备份自动转换生成，无法下载 |
| 我的闪存型号工具没列出   | 按 `[4]` 确认型号；未在适配表内的按标准流程刷正式引导，建议先 `[6]` 备份再操作        |
| 想手动刷机         | 按 `[G]` 查看完整刷机指引与异常排查                                 |
| 想确认刷机过程       | 查看机型目录 `info/` 下的刷机成功日志                               |
